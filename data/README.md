# Dados

`raw/bitcoin_daily_2017_2022.csv` contém a série diária utilizada no projeto, reproduzindo os valores da planilha fornecida no exercício.

Período: **24/03/2017 a 28/02/2022**.

A base possui 1.803 dias consecutivos e não apresenta datas ausentes ou duplicadas.

O arquivo original do exercício não documenta formalmente exchange, moeda ou origem da série; o projeto não atribui uma proveniência externa não documentada.
